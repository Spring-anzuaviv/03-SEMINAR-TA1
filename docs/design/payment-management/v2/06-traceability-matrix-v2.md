## 2. Ma trận chính

Viết tắt:

- Thành phần (02-v2 §2): `API` = PaymentController; `PS` = PaymentService; `PAS` = PaymentApprovalService;
  `PADJ` = PaymentAdjustmentService; `Readers` = IContractReader/IPriceReader/IQuantityReader;
  `Repo` = IPaymentRepository; `AdjRepo` = IAdjustmentRepository; `UoW` = IUnitOfWork;
  `Audit` = IAuditLog; `NotifRepo` = INotificationRepository; `Notifier` = INotifier; `UserDir` = IUserDirectory.
- Bảng dữ liệu (05-v2 §3): `sheets` = payment_sheets; `lines` = payment_lines; `sources` = payment_line_sources;
  `claims` = payment_period_claims; `submissions` = payment_submissions; `notifications` = payment_notifications;
  `adjustments` = payment_adjustments; `changes` = payment_adjustment_changes; `audit` = audit_entries.
- SM = state-machine-v2.

Mọi trạng thái dưới đây kèm **Design Pending Approval**.
